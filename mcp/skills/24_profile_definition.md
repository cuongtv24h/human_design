# SKILL 24: Profile, Definition & Cross

## Mục tiêu
Phân tích Profile, Definition và bốn trụ của Incarnation Cross mà không định mệnh hóa người dùng.

## Tool
- MCP: `analyze_profile_definition`
- REST: `POST /analyze-profile-definition`
- Knowledge: `05_profile_cross_definition.md`

## Quy trình
1. Gọi tool để lấy Profile, Definition groups và bốn Gate Sun/Earth.
2. Giải thích Profile như vai trò và cách học qua trải nghiệm.
3. Giải thích Definition như cách các cụm năng lượng vận hành/kết nối.
4. Dùng Cross như bối cảnh mục đích tổng quát, không khẳng định một nghề duy nhất.
5. Khi cần chi tiết 192 Cross, gọi thêm `get_incarnation_cross_details`.
